## Algunas notas:
<br />

- **Necesitarás una clave de API para usar este plugin**
- **Se ha compilado con Lazarus versión 2.2.6**
- **Probado en Windows 10 y 11, Linux Mint 21.1 de 64 bits TLS y el IDE de Lazarus 2.2.6 + Free Pascal 3.2.2**

<br />

## Cómo instalar


Es casi igual que en Delphi 7: usa el menú principal del IDE para abrir el proyecto, en esta ruta: `Package\Open Package File(.lpk)`, y selecciona el archivo del proyecto del paquete (`lzchatgptwizard.lpk`).
Ahora solo compílalo e instálalo; tardará un poco y el IDE se reiniciará automáticamente.

## Cómo usarlo
Después de configurar tu clave de API en el formulario de configuración, podrás usar el nuevo menú que se ha añadido bajo el menú Tools del menú principal del IDE.
Ahora podrás hacer preguntas directamente y obtener las respuestas.
Alternativamente, puedes presionar Ctrl+Shift+Alt+C para abrir el formulario del complemento.
Nota: este formulario es anclable por defecto; si estás usando paneles anclables, puedes anclarlo a la derecha o a la izquierda.
